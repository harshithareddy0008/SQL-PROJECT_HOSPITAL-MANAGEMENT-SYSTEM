
# Hospital Management System - MySQL

A complete **Hospital Management System** database project built using **MySQL**.  
This project demonstrates relational database design, SQL querying, normalization, advanced SQL concepts, stored programs, transactions, indexing, and reporting.

## Project Overview

The system manages major hospital operations such as:

- Patients
- Departments
- Doctors
- Employees
- Rooms
- Appointments
- Admissions
- Medicines
- Prescriptions
- Payments
- Audit Logs

## How to Run

1. Install **MySQL Server 8.0+** and **MySQL Workbench**.
2. Open MySQL Workbench.
3. Open:

```text
hospital_management.sql
```

4. Connect to your MySQL server.
5. Execute the SQL script.
6. Run the final report queries to verify the project output.

> Some DCL commands such as `CREATE USER`, `GRANT`, and `REVOKE` may require administrator/root privileges.

## MySQL Safe Update Mode

MySQL Workbench may show **Error 1175** for some `UPDATE` or `DELETE` statements when Safe Update Mode is enabled.

For operations that intentionally require broader updates or deletes, Safe Update Mode can be disabled temporarily for the current session:

```sql
SET SQL_SAFE_UPDATES = 0;

-- required UPDATE or DELETE query

SET SQL_SAFE_UPDATES = 1;
```

Always verify the affected rows before running destructive queries.
